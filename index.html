» Tentang Saya

Halo! Nama saya Dadan Hidayat. Saya mahasiswa S1 Teknik Informatika di STMIK Mardira Indonesia, dan saya suka membangun aplikasi yang benar-benar dipakai orang: aplikasi Qur'an, undangan digital, sistem ujian sekolah (CBT), sampai game edukasi anak.
